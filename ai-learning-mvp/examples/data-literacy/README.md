# 03.04 独立练习

复制整个目录后，在 Codex 中打开副本。直接打开 index.html 即可运行，无需安装依赖、账号、API 或数据库。

- tasks.js：两条同名任务的初始数据；每条为独立对象。
- render.js：根据数据绘制页面，勾选时改变当前运行状态。
- index.html：可运行入口，样式内置，复制目录后独立可用。

第一次只读：解释 tasks、对象、id、title、done 与显示逻辑。第二次只改 t02 的标题，核对其余字段和另一条任务。再保存副本、对调顺序，按 ID 修改 t02.done。

本例不持久保存运行状态。修改 tasks.js 后刷新会重新读取源文件；勾选状态刷新后恢复为该文件的初始值。不要把两种修改混为一谈。

恢复：把 tasks.js 的两条记录恢复为 t01/t02、标题“读一章书”、done 为 false。不要对私人项目执行重置。
