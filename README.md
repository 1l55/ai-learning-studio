# AI Learning Studio · AI 学习

**第 1 个正式版本：v1.0.0** · 2026-10-19

为零基础普通人制作的中文 AI 学习网站。从选择和验证 AI 工具开始，逐步学习用 Codex 制作、保存、联网、上线和维护自己的作品。

![课程总览](ai-learning-mvp/assets/course-overview-desktop.png)

## 下载与使用

下载 Release 中的 `ai-learning-studio-v1.0.0.zip`，**完整解压**后使用。仓库源码与发布包都包含教材、网页、测试、独立练习和说明。

### 直接打开

进入 `ai-learning-mvp` 文件夹，打开 `index.html` 或 `course.html`。不要只复制一个HTML文件，也不要直接在压缩包内打开。各浏览器对本地文件与存储的限制不同；本版主要通过本地HTTP验收，推荐使用下面的方法。

### 推荐：本地预览

准备 Node.js 24 或更新版本。在解压后的项目根目录打开终端：

```sh
node --version
npm start
```

**无需 npm install**，没有第三方运行依赖。在浏览器打开 <http://127.0.0.1:8766/>，终端保持运行。结束时按 Ctrl+C。端口被占用时运行 `npm start -- 8777`，再打开对应端口。

也可使用已有的静态服务器：Python可用时，从项目根目录运行 `python -m http.server 8766 --bind 127.0.0.1`，访问 <http://127.0.0.1:8766/ai-learning-mvp/course.html>。只让本机预览；演示后端不用于公开服务。

## 课程与学习方法

| 路线 | 模块 | 主课数量 | 目标 |
| --- | --- | ---: | --- |
| 通用 AI | 01 → 04 → 05 | 17 | 整理资料、比较方案、选择工具并核实结果 |
| 本地创作 | 01—07 | 43 | 用 Codex 做出可修改、可保存和恢复的小工具 |
| 联网应用 | 01—13 | 80 | 理解前后端、数据库、身份隔离、部署与维护 |

另有4项入门准备、5个拓展和5次阶段验收。文件操作不熟悉时，从总览底部的P01开始。

每课依次是先猜、原理、实验、实践与自检。教材包含160个条件变化案例、400道带逐选项理由的判断题，以及独立操作步骤、Codex任务说明和验收证据。预制案例明确标为教学推演；03.04、05.02增强样课和03.05按钮实验提供实际网页操作。

阅读、课内练习与外部实践分别记录。“课内完成”要求阅读和判断题通过；“自行验收”需要核对自己的真实作品，勾选不是系统认证。进度和笔记保存在当前浏览器，可逐课导出。

后端数据库练习：解压 [08—09练习包](ai-learning-mvp/examples/08-09-backend-lab.zip)，按[README](ai-learning-mvp/examples/backend-lab/README.md)启动真实HTTP与SQLite示例。它只监听本机，不含登录和多用户隔离，不应直接公开部署。

## 隐私与发布范围

- 学习网站不要求账号、密钥；无模型调用、统计代码、第三方脚本或远程字体。
- 记录不自动上传，分享源码不包含你的浏览器记录。请不要在笔记、截图、数据库或Issue中放入密码、密钥和个人资料。
- 公开仓库使用筛选后的源码快照，不上传原工作区历史、本机诊断、权限备份、配置目录、数据库、日志和其他工程。
- Release ZIP不包含 `.git`；独立发布仓库只保留本次发布的干净历史，提交身份使用GitHub noreply地址。

详情见 [PRIVACY.md](PRIVACY.md)。版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 开发与校验

```sh
npm run build
npm test
```

内容源在 `ai-learning-mvp/content/modules/01.json`—`13.json`。修改教材后重新构建 `content/course-data.js`。测试覆盖课程编号、内容合同、路线、进度、实际实验、HTTP/SQLite以及发布筛选；结构和字符数校验不能单独证明教学效果。

项目结构：`ai-learning-mvp/` 网站与练习；`docs/curriculum/` 总纲；`scripts/` 构建与本地预览；`tests/` 发布与预览测试。更详细的学习说明见 [网站README](ai-learning-mvp/README.md)。

维护发布时，先人工核对 `release-files.json` 的逐文件清单，再运行 `npm run release:prepare`。新增文件不会自动进入发布包；即使放在课程目录，也必须明确加入清单。发布脚本拒绝已有非空输出目录，避免覆盖未经核对的内容。
